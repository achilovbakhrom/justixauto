## Scope limits

This is an adapter primitive: owner admission authorizes subscribers and payloads,
binds all repositories to one UnitOfWork transaction and propagates errors. A
valid routing owner is not an authorization grant. No broker publish occurs here.
No relay/confirm, transport exactly-once, multi-recipient delivery, checkpoint,
quarantine or complete B-01 acceptance claim is made. The one-target schema and
the coordinator's messaging-readiness gap remain explicit downstream constraints.
Browser verification is inapplicable to this backend task.
