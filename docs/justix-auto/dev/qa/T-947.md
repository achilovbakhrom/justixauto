## Blocking finding Q1 — repeated empty initial enrollment

`pkg/inbox/membership_catalog.go:675`–715 tracks enrollment UUIDs, event position/
hash consistency, and `(event,consumer)` job duplicates, but does not track the
initial enrollment identity per event. With an empty applicable consumer set,
the job loop runs zero times and each distinct initial enrollment independently
satisfies `len(Consumers)==0`. Two initial enrollments for the same event are
therefore sealed as valid. `NewTransitionRequest` and its canonical decoder both
accept this self-contradictory supplied request.

This violates [messaging delivery §4](../../state/drafts/contracts/messaging-delivery.md)
line 197: “exactly one initial enrollment per message”; lines 207–213 also require
complete immutable enrollment identity. The
[membership contract](../../state/drafts/contracts/membership-version-storage.md)
lines 239–249 preserves the message's initial enrollment identity and exact sets.
This is a supplied-value consistency check, with no retained storage or source
authority lookup required. Later SQL rejection does not make the accepted pure
identity a consistent request.

[Independent regression](T-947/independent_test.go),
`TestQARejectTwoEmptyInitialEnrollmentsForOneEvent`, constructs an approved-shaped
empty catalog/owner selection, one explicitly enumerated source stream with
zero-applicable evidence, boundary 1 and one empty initial enrollment. That valid
control round-trips successfully. The counterexample adds a second initial
enrollment with the same event UUID, position and envelope digest, but a different
enrollment UUID and effect digest. The exact observed failure is:

```text
accepted two distinct initial enrollments for event 10000000-0000-4000-8000-000000000003:
constructor Valid=true, canonical decoder Valid=true err=<nil>, backlog=2
```

The regression command exits 1; [raw output](T-947/independent.log) is retained.
Required correction: reject multiple supplied initial enrollment identities for
one event independently of recipient cardinality, while retaining the valid
single empty initial enrollment and existing legitimate late-delta semantics.
Add an implementation regression and submit a new exact SHA for independent QA.
