## Scope and limitations

GREEN is for append/transaction mechanics. Immutable event construction and
schema-bound payload admission remain enforced; per-event company metadata is
preserved without adding an unapproved universal transfer restriction. Owner
commands must authorize business transitions. The typed binding factory is an
adapter composition contract: it must bind every repository to the supplied
transaction and keep ports within the callback. Callers must propagate append
errors and should supply all affected streams in one Append call for sorted
locking. No automatic callback retry is introduced.

Replay, production outbox/receipt adapters, owner authorization, command hashing
and end-to-end recovery remain downstream tasks. No frontend surface changed,
so browser parity is not applicable. This report does not close parent B-01 AC2.
