The independent adversarial suite passed under `-race` in `41.624s`. It proved:

- actual in-memory TLS 1.3 server handshakes reject a missing client
  certificate, a client certificate from an untrusted CA, and a server-auth-only
  certificate presented as a client certificate;
- a correctly trusted client-auth certificate carrying only DNS/common-name
  identity completes TLS but resolves to `ErrUnknownPeerIdentity`;
- a URI SAN on a non-leaf certificate is ignored;
- unknown, disabled, two-distinct configured identities, unverified chains and
  chain/leaf mismatch remain denied, and duplicate-identical configured URI SAN
  occurrences are now denied;
- path traversal, percent-encoded traversal and double-slash URI variants do not
  normalize into a configured identity;
- canonical, lower-case, underscore, duplicate-map-key variants and multi-value
  actor/permission/internal headers are all rejected and removed from the proxy
  copy while `X-Context-Revision` remains and the inbound header map is unchanged;
- grants remain exact and deny unknown caller/action/purpose combinations;
  caller/action/purpose constructor input mutation and concurrent authorization
  reads do not broaden access. Duplicate identical grant entries preserve the
  same exact grant and create no wildcard behavior.
