## Blocking findings

### 1. A partially completed multi-artifact run can report overall success

`runPrivate` records `driver.LastAttempt()` after `engine.Up()` fails and then
maps any `RecordedCompletion` result from `Reconcile` to a nil overall error.
It does not require the reconciled version to equal the requested profile head.

The independent real PostgreSQL probe starts at clean version 1 with one sealed
profile targeting `[1,12,17]`. Version 12 commits normally. Before version 17's
dirty transition, the probe changes only version 17's disposable fixture file,
so T-932's repeated file preflight rejects it. The original bytes are restored
only as the runner opens its fresh reconciliation connection. Reconciliation
correctly proves that version 12 completed, but T-933 incorrectly returns:

```text
nil error; status=recorded-completion; result version=12
database ledger=12:false; receipts=1,12; version-17 namespace absent
```

This violates the exact requested-head, complete-bundle and failure-recovery
contract. It can tell orchestration that a migration command completed while the
requested immutable head and feature are absent. Reconciliation of an
intermediate artifact may preserve/record its authoritative outcome, but it must
not turn failure to reach the requested head into overall success.

Reproduction: [independent_test.go](T-933/independent_test.go),
`TestQA933IntermediateCompletionIsNotOverallSuccess`. Exact observed state and
fixture identity are in [observations.md](T-933/observations.md).

### 2. Malformed resolved reports release the durable evidence path

`requireResolvedReport` validates only revision, owner, database, profile digest
and status. It accepts a `recorded-completion` report with a nonexistent version,
missing request, wrong SQL digest or missing provenance, and accepts a
`verified-no-op` report whose version is not the profile head. A later private
run can therefore overwrite a report that never represented the exact successful
finalization/no-op asserted by its status.

Reproduction: [independent_test.go](T-933/independent_test.go),
`TestQA933MalformedResolvedReportCannotReleasePath`; all five adversarial cases
failed the QA expectation. This is secondary to the false overall-success bug
but independently violates the runner's exact durable-report boundary.
