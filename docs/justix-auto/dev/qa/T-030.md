## Independent evidence and risk coverage

- **Transaction and failure recovery:** readiness is rechecked inside the actual
  `READ COMMITTED` transaction before repository binding. Post-BEGIN ledger
  drift rejects the transaction. Callback/factory errors, panic and cancellation
  roll back effects. A lost reply after a real commit and after a real rollback
  is classified as unknown; authoritative receipt recovery distinguishes them.
- **Duplicates and replay:** six concurrent identical commands converge to one
  event, command receipt and operation. Same-key/same-payload replay succeeds;
  changed payload conflicts. Aggregate replay reads the committed event, and
  uncommitted history remains invisible.
- **Permissions and isolation:** exact database, `current_user`, `session_user`,
  clean v1 ledger, owner marker, required grants and forbidden table/column /
  PUBLIC / reachable-NOINHERIT privileges are checked. Migration owner,
  privileged `SET ROLE` masquerade and connections to the other six owner
  databases are denied before feature binding/callback.
- **Migration safety:** absent shared mechanics, wrong database/role, clean,
  missing, wrong-version or multi-row runner ledgers, and a foreign shared owner
  default fail before the private marker is created. The valid migration retains
  the runner's dirty ledger for the runner to finalize; reapplication fails.
- **Mode compatibility:** pre-additive legacy remains supported. Once additive
  metadata exists, wrong owner/runtime/revision/singleton/cardinality/table owner,
  RLS, excess column privilege, missing/substituted marker and actual custody
  mode all fail closed before binding. Restoring legacy outbox grants does not
  make custody mode acceptable.
- **History preservation:** readiness and replay were executed against a
  populated fixture containing one Documents event, receipt and operation;
  byte-exact before/after snapshots match.
- **Fixture safety:** allocation-failure and lost-create-reply paths clean only a
  validated immutable container identity. Final audit found no referenced
  container or volume residue.
