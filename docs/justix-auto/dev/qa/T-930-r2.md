## Remaining blocking finding

**P2 — digest arrays are silently truncated, padded or null-normalized.**
`pkg/persistence/profile.go:506`, `:515` and `:521` validate exact identity field
names but not the raw SHA256 array's shape or element types. The subsequent
ordinary JSON decoder into `Digest [32]byte` can discard information before
the exact typed identity comparison:

- Append a 33rd element to an otherwise correct SHA256 array. A byte, `null`,
  or an object containing an unknown field is discarded. All three forms pass
  `VerifyFiles` at artifact, prerequisite and feature identity locations.
- For a nonzero feature digest with a zero final byte, omit that final element.
  The decoder pads it with zero, and verification incorrectly succeeds.
- For that feature digest with a zero first byte, replace it with `null`.
  The decoder leaves zero and verification incorrectly succeeds.

The probe hashes each exact malformed manifest into its trusted profile and
keeps the real SQL-file digests correct; failures cannot be attributed to an
unrelated hash mismatch or invalid fixture setup. Every control with the full
valid 32-byte digest succeeds. Eleven malformed cases are accepted across
eighteen digest cases. The artifact/prerequisite shortened and null-byte cases
reject only because their particular expected byte is nonzero, demonstrating
why relying on the final digest comparison is insufficient.

Require exactly 32 valid integer bytes for every raw digest, with no truncation,
zero-fill or null coercion before typed decoding. Keep the duplicate-key,
Unicode and exact-name fixes. A trusted byte hash establishes which bytes were
provided; it does not make their malformed declared structure valid. This is a
bounded representation defect in the existing manifest contract, not a request
for a new profile format or broader runtime policy.

Reproduction: [new independent probe](T-930-r2/independent_r2_test.go),
[overlay](T-930-r2/overlay.json), [failed run](T-930-r2/new-probes.log).
This is the first new-probe attempt, preserved unchanged; no harness failure
or application fix occurred during QA.
