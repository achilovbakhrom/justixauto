method or ACK hook on `TransactionalConsumer`. It binds the typed owner ports
to the supplied SQL transaction and rejects plain pools. `Apply` validates
before every lookup, checks exact received-byte identity, and returns a duplicate
candidate without invoking the effect. The caller can therefore complete its

committed receipts; rollback and unknown commit must discard them and reconcile
both inbox and job state.

original T-008-only installations. ACK follows confirmed local commit. Active
custody mode rejects both fresh and duplicate direct calls before effect/ACK.

errors. Custody uses a transaction-local compatibility marker, not authorization.
