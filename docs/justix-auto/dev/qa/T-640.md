## Findings

1. **P2 — dangling output symlink bypasses the no-follow guard.**
   `tools/generate-contracts.mjs:533` conditions `lstatSync` on `existsSync`.
   A dangling link returns false from `existsSync`, so it passes both the link
   and existing-file checks. With `fixture.ts` linked to a nonexistent synthetic
   path outside its config directory, generation exits 0 and creates that target.
   This violates the explicit output-path authority and advertised symlink
   rejection. Use a link-aware check that distinguishes an absent directory
   entry from an existing dangling link; reject before writing either output.
   Add a regression that verifies the link is preserved, its target is absent,
   and other planned outputs remain untouched.

2. **P2 — accepted component names produce uncompilable output.**
   The emitted-symbol checks around `tools/generate-contracts.mjs:148` and `:205`
   omit imported TypeScript names and the Go constructor. Adding any one of the
   otherwise valid string schemas `ApiRequest`, `ApiResult` or
   `NewContractClient` to the fixture succeeds and writes both files. Actual
   TypeScript compilation fails for the first two with TS2440 import/local
   declaration conflicts; actual Go compilation fails for the third because
   `FixtureNewContractClient` is redeclared as a type and function. Reserve or
   safely alias every emitted/imported symbol before writing. Regression cases
   must require either clean compilation or explicit rejection without changing
   previously generated outputs.

3. **P2 — TypeScript typed-map keys admit malformed Unicode rejected by Go.**
   The object branch at `tools/generate-contracts.mjs:327` validates map values
   but not the Unicode scalar validity of keys. `PayloadSchema.parse` accepts
   `metadata: {'\ud800': 'x'}`; the generated Go decoder rejects its JSON
   representation. A valid supplementary-character key succeeds in both.
   This mismatch is visible in the already-decoded JS value, so it is separate
   from the explicitly deferred raw-browser duplicate-key/number-lexeme handoff.
   Apply the same malformed-Unicode rejection to map keys and cover both lone
   high/low surrogates and valid pairs. Do not normalize or drop keys silently.
