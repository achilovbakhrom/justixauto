## Implemented boundary

Private `renderAuthValidatorsTS` / `renderAuthValidatorsGo` fragments consume the
T-937 compiled auth model. They have no HTTP transport, injected exchange, token
sink, session state or default policy. Main and both complete renderers still
unconditionally reject auth output; the tests invoke the private fragments only
inside a temporary copy with the CLI entry removed. No export, environment,
configuration or command-line activation mechanism was added.

TypeScript emits the exact five primitive outcome strings, mandatory typed
`AuthSemantics`, explicit `NameStructuralSchema` parsers and the bound
`createAuthValidators` factory. Construction inspects own descriptors of a plain
function table, rejects missing/nonfunction/accessor definitions without invoking
getters, captures references and freezes dispatch. Full validation uses only the
captured functions. Later mutations of the source table cannot replace a hook.

Go emits namespaced nonzero uint8 outcomes 1–5, a mandatory typed interface,
constructor and bound `ParseName` owner-input validators. Nil and typed-nil
pointer/map/slice/function bindings reject. Method references are captured once;
narrow guarded dispatch turns panics, zero and unknown outcomes into the constant
FatalBinding category. Raw DTO marshal/unmarshal remains structural only. Auth
root reference DTOs use aliases so referenced union marshal/unmarshal behavior
is retained; the semantic walker still records each alias occurrence separately.

Readiness runs at construction, each top-level full validation and immediately
before every named/ref and operation error hook. Readiness Mismatch is
FatalBinding. Absent policy/configuration has no generated fallback. Hooks remain
trusted pure synchronous functions under the approved contract, not a plugin
sandbox.

The complete structural tree and all union cardinalities are validated first.
Only the private ordinary mismatch sentinel counts as a nonmatching alternative;
missing/changed generated schemas, unexpected exceptions/panics and invalid
configuration abort globally. Exactly one alternative must match before any
semantic hook runs. The selected tree records each named/ref occurrence, including
repeated array/map entries and aliases, then dispatches child → union → parent.
Map keys have a stable sorted traversal in both languages. Go prepares all typed
hook arguments and the root/error value before the first semantic callback;
conversion/configuration failures cannot leave a partially validated tree.

Mismatch and all fatal semantic outcomes abort without trying another branch.
The operation/status error hook runs last against the exact trusted declaration.
The approved 2026-09-16 representation refinement is implemented as a TS union
and a Go wrapper with one typed pointer per error schema (a single schema uses an
alias). Empty/multiple/wrong wrapper alternatives and wrong operation/status
selection reject before the error hook. New types, structural exports, wrapper
fields and method names participate in collision checks. No public untyped
error-payload escape or wire-schema change is introduced.

TS guarded hooks accept only exact primitive strings. Returned or thrown native
Promises—including ordinary cross-realm Promises—are rejected synchronously and
their rejection is observed separately using captured `Promise.prototype.then`
and constant handlers. No arbitrary thenable is assimilated; outcome `then`/`kind`
getters are not read, and no rejection reason is formatted or returned. Promise
proxies, hostile species/constructor overrides and independent unreturned async
work remain outside the approved supported binding model.
