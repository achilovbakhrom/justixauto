All are native disabled buttons; zero pages are registered. The organization
selector displays only the injected current organization and is disabled. No
cross-company switching, account mutation or extra navigation is implemented.

horizontal navigation at <=600px. The account header wraps at <=900px. The
sidebar is normal grid content, unlike the sticky Admin or fixed finance shell.

The local Vite development and preview guards match the reviewed T-038 request
intent rules. They serve entry HTML only for explicit positive-quality HTML
document requests inside the Insurance prefix; wildcard fetch/script requests,
direct or encoded HTML fetches, API/missing asset paths, sibling prefixes and
non-GET/HEAD fallbacks are rejected. Valid navigation still loads Vite modules.
These local guards do not implement a deployment edge proxy or authorization.
