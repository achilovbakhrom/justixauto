## Outcome

Implemented the shared event-envelope mechanics in `pkg/events` without adding
domain event names or transport behavior. The envelope derives and allowlists
the seven approved owners from the versioned event type; validates canonical
UUID metadata, aggregate identity, positive aggregate revision and independent
positive integration sequence, company/global-identity scope, actor kind, and
UTC occurrence time. Aggregate revision and integration sequence deliberately
remain separate values because internal-only aggregate revisions do not consume
integration positions.

Payload bytes are copied at construction and on access. An owner-declared typed
event schema is explicitly bound to one event type, schema version, aggregate
type and company scope. The same immutable descriptor is required to construct
and decode a typed envelope. It rejects mismatched aggregate claims and unknown
fields, and requires its owner package to validate required business fields.
The shared package therefore enforces version selection without defining any
business event type. Construction and wire decoding
reject non-object/malformed JSON and recursively reject secret or raw-PII field
names while allowing explicit reference/ID fields. This structural guard is a
defense at the shared boundary; owner event types must still use allowlisted
schemas and must never place sensitive content under neutral field names.

`Revision` accepts the full non-negative signed-int64 range and serializes only
as a canonical base-10 JSON string. It rejects signs, leading zeros, decimal
notation, JSON numbers, negatives and overflow, and detects increment overflow.
No database conversion was added: the repository import-boundary test requires
storage behavior to remain in adapters.

Fix cycle 1 added the observed `BirthDate`, `surname` and `mobile` forms to
case-normalized recursive PII rejection and added explicit decoder
schema-mismatch and missing-required-field regressions.

Coordinator review after the second QA bounce removed the shared identity
aggregate allowlist. Shared mechanics no longer classify identity business
aggregates or expose an independent aggregate field in construction input.
Owner schemas declare tenant-required or global-allowed scope together with the
exact event and aggregate type. Raw wire unmarshalling performs structural
validation only; the bytes do not become an accepted typed payload until they
match an owner schema and its validator. Auth-record/public-event exclusions
therefore remain in the owner's approved descriptor set rather than being
invented as shared aggregate categories.
