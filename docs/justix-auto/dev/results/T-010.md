  deterministic reconstruction, concurrency and real PostgreSQL coverage.

`Loader.Load` reads one complete stream in one ordered SQL statement, checks
every aggregate revision and separately checks emitted integration positions.
Internal-only events retain SQL NULL semantics and expose sequence zero to
replay handlers. A missing stream returns `ErrAggregateNotFound`; cancellation,
storage failures and corrupt history remain errors and never authorize creation.
The adapter must remain outside owner domain/app/port packages. Owners expose
their own typed load ports and condition writes on the returned revision.

`Replay` validates every record and typed payload before constructing a fresh
aggregate or invoking any transition. Duplicate event IDs, missing/out-of-order
revisions, mixed streams/owners, integration gaps and unsupported schemas fail
closed. An owner transition error returns no partial result. The shared layer
does not impose company immutability or grant company/actor authorization.

Owners register current schemas through `DecodeWith` and direct historical-to-
current mappings through `UpcastWith`. Both source and target schemas validate
the data. Upcasting must advance the schema version without changing owner or
aggregate type. Original IDs, event metadata and stored bytes stay unchanged.
Owner transforms/validators and transition callbacks must be pure and
deterministic; fresh aggregate state must be isolated until replay succeeds.
No runtime mechanism can prove an arbitrary Go callback is pure; owner task QA
must verify that contract. Typed reference fixtures demonstrate replay through a
tombstone without any private-record client, table or lookup.
