## Fix cycle 1 — credential failure path

Independent QA bounced `f80d8f2b1d5600101b607f6840f357cde13cd91d`
because PostgreSQL 18 ignores the argument to psql's `\quit` and exits zero.
The bootstrap now initializes every psql password variable to empty, reads the
environment, and raises a real PostgreSQL division-by-zero error under
`ON_ERROR_STOP` for each omitted or empty value. The error occurs before the
bootstrap temp table, roles, or databases are created. This also avoids an
undefined-variable syntax error when `\getenv` cannot find an environment value.

The automated Docker regression uses the exact pinned image without host ports.
It starts a fresh empty data directory for each of 14 cases: omitted and empty
values for every one of the seven credential variables. Every case must exit
nonzero, name the rejected variable, emit no `CREATE ROLE`/`CREATE DATABASE`,
and never report `PostgreSQL init process complete`.

## Delivered

- `infra/local/postgres/init-owners.sql` creates seven restricted login roles
  and seven separately owned databases. It requires injected passwords, revokes
  `PUBLIC` access, explicitly revokes all 42 cross-owner database privilege
  pairs, and grants each owner access only to its matching store.
- `infra/local/postgres/README.md` pins PostgreSQL 18.6/Alpine 3.24 by the
  approved ADR-13 digest and documents a disposable loopback-only fixture with
  synthetic credentials and no seed data.
- `tests/integration/database_isolation_test.go` checks the exact server version,
  database ownership, restricted role capabilities, catalog privileges, all 42
  forbidden connection pairs, concurrent owner-local writes using the same table
  name, transaction rollback, and all 14 bootstrap credential failure cases.

This slice provisions empty local databases only. It does not introduce shared
business tables, cross-database foreign keys, migrations, production accounts,
broker semantics, events, replay, projections, or application behavior. Aggregate
replay and domain-command invariants are therefore not applicable to this task.
