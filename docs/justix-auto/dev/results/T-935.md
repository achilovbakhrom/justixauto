## Delivered boundary

Only `web/packages/api/src/responseJSON.ts`, `responseJSON.test.ts` and this
result changed. One iterative raw-byte grammar parser rejects fatal UTF-8,
BOM/non-JSON whitespace, duplicate decoded names, lone surrogates, malformed
escapes, non-JSON numbers and trailing content before returning any value.
Null-prototype records and own data properties preserve special names without
prototype mutation; Unicode names are exact and are not normalized.

`decodeResponseJSON(bytes, numeric, limits?)` supports `finite-json` legacy
finite Number semantics and `safe-integers` exact decimal/exponent integrality
and bounds before conversion. It retains negative zero, supports exact exponent
cancellation and caps exponent arithmetic before constructing at most 16 final
integer digits. No BigInt/power allocation depends on an untrusted exponent.
String numbers remain strings; later schemas still own endpoint validation.

`defaultResponseJSONLimits` is frozen at 8 MiB / 128 container levels.
`responseJSONLimits` validates positive safe integer settings and returns a
separate frozen snapshot. An optional decoder limits argument supports the
approved future client construction settings; no header-derived bounds exist.
Explicit frames permit larger trusted configured depth without JS recursion.
Byte bounds are checked before UTF-8 decoding; failures contain no payload.

T-936 still owns Fetch stream counting/cancellation, client construction and
actual transport integration. Existing client/exports/generator/schema files
are unchanged. No auth metadata, tokens, cookies, retries, UI or policy is
implemented by this leaf. This parser does not claim bounded network reads or
authorization. T-002 release/security settings remain unaccepted.

package parity

import (
 "encoding/json"
 "os"
 "testing"
)

func TestActualGeneratedDecoderParity(t *testing.T) {
 data, err := os.ReadFile("vectors.json")
 if err != nil { t.Fatal(err) }
 var vectors []struct{ Source string; Valid bool; Value any }
 if err := json.Unmarshal(data, &vectors); err != nil { t.Fatal(err) }
 for _, v := range vectors {
  actual, err := parityContractRead([]byte(v.Source))
  if (err == nil) != v.Valid { t.Fatalf("acceptance mismatch %q: %v", v.Source, err) }
  if !v.Valid { continue }
  normalized, err := json.Marshal(actual)
  if err != nil { t.Fatal(err) }
  var observed any
  if err := json.Unmarshal(normalized, &observed); err != nil { t.Fatal(err) }
  want, _ := json.Marshal(v.Value)
  got, _ := json.Marshal(observed)
  if string(got) != string(want) { t.Fatalf("value mismatch %q: %s / %s", v.Source, got, want) }
 }
 t.Logf("Actual generated Go decoder matches TypeScript on %d vectors", len(vectors))
}
