## Implemented boundary

`@justixauto/ui` exports `./Dialog`, `./Field`, and `./Button`. Radix owns modal
focus trapping/restoration and background isolation. The controlled dialog
requires an accessible title, description, close label, trigger and explicit
four-app token scope. The matching scope is retained on the portalled overlay,
so insurer/Admin colors, dimensions and responsive padding remain available.
Children, optional icon, and footer are composition slots; no application menu,
row behavior, domain commands, persistence or auth are introduced.

Clean Escape, close-button and outside-pointer dismissal request `open=false`.
Inside clicks do not dismiss. Dirty dismissal is vetoed and reported through
`onDismissBlocked(reason, 'dirty')`; the owning page supplies any separately
approved discard interaction. Processing also vetoes dismissal, reports
`processing`, disables the close button and exposes `aria-busy`. A parent can
still authoritatively clear `open` for a context change. Modal closure never
claims to cancel a server command. Custom footer actions belong to their form
owner and must respect its dirty/processing state; the synthetic fixture tests
that contract rather than inventing durable cancellation behavior.

Field uses a generated or supplied ID, native label association, composed
hint/error descriptions and announced validation errors. Validation rules and
submission remain caller-owned. Button defaults to `type=button` to avoid
accidental form submission; processing uses native disabled plus `aria-busy`.
Existing HTML SVG close artwork is retained for common Realization/Financing
dialogs; distinct insurer/Admin close glyphs and modal radii are preserved.
All component CSS stays inside the explicitly owned TSX leaves; the immutable
CSS token package supplies shared values. No extra application CSS file was
added outside ownership.
