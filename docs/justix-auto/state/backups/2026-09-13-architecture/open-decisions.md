## Уже разрешённые расхождения — не задавать пользователю снова

- Одно приложение Реализация; отдельные Dealer/Distributor не возвращаются. Банк и МФО пользуются одним отдельным приложением Финансирование; Страховая и Admin самостоятельны.
- Отдельные «Склады» и «Автомобили» в sidebar, contextual документы, компании/филиалы в Settings. Старый шестипунктный distributor sidebar не текущая навигация.
- CRM заменяет отдельные «Обращения»; импорт/приёмка доступны из владельца процесса, не отдельными обязательными модулями. Продуктовый модуль споров исключён.
- «От партнёров» удалено из billing по запросу 2026-09-05. Оплаты оптового заказа остаются в карточке.
- Seller companies, Users и Roles уже добавлены в Admin R2; тексты «ещё не реализовано» из первого intake/README относятся к прошлому этапу.
- Credentials нового first provider admin заменили необходимость отдельного приглашения для этого сценария; открытого пароля в audit быть не должно.
- Finance больше не ограничивается seller-калькулятором: есть отдельный financier round trip и post-agreement документы. Старые `submitted-demo` helper/status и intake «кабинет отложен» не текущая общая state machine.

## Известные ограничения доказательств

Доменные тесты в `prototype/*test.cjs` описывают guards/арифметику demo, не production backend. Ранее browser commit для отзыва membership/custom role был отклонён инструментом; полный browser upload/review финансовых файлов не пройден из-за доступа file picker. Не выдавать эти шаги за QA green. Локальные Web Locks, snapshots и history не доказывают серверную конкурентную безопасность, tenant isolation или event sourcing.
