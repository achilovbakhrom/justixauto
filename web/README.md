# React applications — reserved

React is confirmed. Four apps share a component/design layer: Realization,
Financing (MFO/bank), Insurance, Admin. Do not create separate dealer/distributor
apps. The architecture stage will select and pin React/build tooling, routing,
forms, client data handling and package structure. Proposed default: TypeScript
and Vite with npm workspaces; this is not yet an approved or installed stack.
HTML references live in docs/justix-auto/mocks, not application source.
